# Exercise 21: Test Weak Cryptography Vulnerabilities using AI

## Objective
Use **ChatGPT** to generate a shell script that automates testing for:

- Weak SSL Ciphers
- Insufficient TLS Configuration
- Weak Encoding Techniques

---

# Tools Used

- ChatGPT
- OpenSSL
- Nmap (ssl-enum-ciphers)
- testssl.sh (or equivalent)
- curl

---

# Step 1: Generate the Shell Script

Open ChatGPT and enter:

```text
Generate a shell script to test web applications (e.g., www.certifiedhacker.com) for insufficient transport layer security, weak SSL ciphers, and weak encoding techniques. It should organize and display the results in clearly labeled sections for each type of information and save the results in a text file. The script should install all the required dependencies and libraries.
```

Save the generated script as:

```text
TestWeakCryptography.sh
```

---

# Step 2: Convert to Unix Format

```bash
dos2unix TestWeakCryptography.sh
```

---

# Step 3: Make the Script Executable

```bash
chmod +x TestWeakCryptography.sh
```

---

# Step 4: Execute the Script

```bash
./TestWeakCryptography.sh
```

When prompted, enter:

```text
www.certifiedhacker.com
```

---

# What Does the Script Check?

## 1. Insufficient TLS

Checks:

- TLS Version
- SSL Version
- Deprecated Protocols

Example:

```text
TLS 1.0
TLS 1.1
TLS 1.2
TLS 1.3
```

---

## 2. Weak SSL Ciphers

Looks for weak ciphers such as:

```text
RC4
DES
3DES
NULL
EXPORT
```

---

## 3. Weak Encoding Techniques

Checks for:

- Weak Base64 Usage
- Insecure Encodings
- Poor Cryptographic Configuration

---

# Output File

Results are saved in:

```text
Transport_Layer_Security_Results.txt
```

Review the file for:

- TLS Version
- Weak SSL Ciphers
- Weak Encoding Findings
