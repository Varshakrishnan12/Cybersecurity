# Exercise 20: Test Application Deployment & Configuration using AI

## Objective
Use **ChatGPT** to generate a shell script that automates basic web application security checks using **Nikto** and **Gobuster**.

---

# Tools Used

- ChatGPT
- Nikto
- Gobuster

---

# Step 1: Generate the Shell Script

Open ChatGPT and enter:

```text
Generate shell script to test web application (e.g., www.luxurytreats.com) platform configuration using nikto, test handling of file extensions for sensitive information using nikto, and discover old backups and unreferenced files using Gobuster. The command should organize and display the results in clearly labeled sections for each type of information.
```

Save the generated script as:

```text
TestConfiguration.sh
```

---

# Step 2: Convert Script Format (if required)

```bash
dos2unix TestConfiguration.sh
```

**Purpose**
- Converts Windows (DOS) line endings to Unix format.

---

# Step 3: Give Execute Permission

```bash
chmod +x TestConfiguration.sh
```

**Purpose**
- Makes the script executable.

---

# Step 4: Execute the Script

```bash
./TestConfiguration.sh
```

When prompted, enter:

```text
http://www.luxurytreats.com
```

---

# What Does the Script Do?

## 1. Platform Configuration Check

Uses:

```bash
Nikto
```

Checks:

- Web Server
- IIS Version
- Server Configuration
- Known Misconfigurations

---

## 2. Sensitive File Extension Check

Uses:

```bash
Nikto
```

Looks for exposed files such as:

```text
.bak
.old
.zip
.config
```

---

## 3. Backup & Hidden File Discovery

Uses:

```bash
Gobuster
```

Finds:

- Hidden Directories
- Backup Files
- Unreferenced Files
- Admin Pages

---

# Output

Results are saved in:

```text
WebApp_Test_Results.txt
```

Review the file for:

- IIS Version ✅ (Lab Answer)
- Nikto Findings
- Gobuster Findings
- Hidden Files/Folders

# Key Learning

- AI can automate repetitive penetration testing tasks.
- Nikto identifies web server information, IIS version, and common misconfigurations.

- Automation improves efficiency and ensures consistent security assessments.
