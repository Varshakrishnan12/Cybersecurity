# Exercise 13 – Stored XSS & Parameter Manipulation (CPENT Cheat Sheet)

## Objective
Identify:
- Stored XSS
- Session Hijacking
- Plain-text Cookies
- Parameter Manipulation (IDOR)

---

# Step 1 – Login as Normal User

- Open `http://www.moviescope.com`
- Login:
  - Username: `steve`
  - Password: `test`

---

# Step 2 – Stored XSS

- Go to **Blog**
- Paste the provided XSS payload in **Leave a Comment**
- Submit the comment

**Result:** Malicious comment is stored.

---

# Step 3 – Trigger XSS

- Login as Admin
  - Username: `sam`
  - Password: `test`
- Open **Blog**
- Click **"Please click here to visit website"**

**Result:** Admin cookie is sent to the attacker.

---

# Step 4 – Verify Cookie

Open:

```
C:\inetpub\wwwroot\oceanplaza\CookieSteal\Mycookies.txt
```

**Result:** Admin session cookie is stored in plain text.

---

# Step 5 – Session Hijacking

- Open **Developer Tools (F12)**
- Application → Storage → Cookies → **moviescope**
- Edit **mscope** cookie
- Replace it with the value from **Mycookies.txt**
- Refresh the page

**Result:** Logged in as **Sam (Admin)**.

---

# Step 6 – Parameter Manipulation

Open:

```
Profile.aspx?id=1
```

Change to:

```
id=2
id=3
id=5
```

**Result:** Other users' profiles open without authorization.

---

# Vulnerabilities Found

- ✅ Stored XSS
- ✅ Plain-text Session Cookie
- ✅ Session Hijacking
- ✅ Parameter Manipulation (IDOR)

---

# Conclusion

The application is vulnerable to:
- Stored Cross-Site Scripting (Stored XSS)
- Cookie Theft & Session Hijacking
- Parameter Manipulation (IDOR)
- Unauthorized access to user data
