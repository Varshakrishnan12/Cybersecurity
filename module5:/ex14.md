# Exercise 14 – Performing a Local File Inclusion (LFI) Attack

## Objective
Learn how to identify and exploit a **Local File Inclusion (LFI)** vulnerability using the **bWAPP** web application.

---

# What is LFI?

**Local File Inclusion (LFI)** occurs when a web application allows user input to include files from the server without proper validation.

Example:

Normal:
```
language=english.php
```

Attacker changes it to:

```
language=/etc/passwd
```

If the application displays the file, it is vulnerable to **LFI**.

# Why /etc/passwd?

The `/etc/passwd` file contains:

- Usernames
- User IDs (UID)
- Home directories
- Login shells

It is commonly used to verify an LFI vulnerability.

---

# Vulnerabilities Found

- Local File Inclusion (LFI)
- Improper Input Validation
- Sensitive File Disclosure

---

# Risks

- Read sensitive files
- Leak configuration files
- Reveal database credentials
- May lead to Remote Code Execution (RCE) in some cases

---

# Prevention

- Validate all user input
- Allow only whitelisted files
- Prevent directory traversal
- Use proper access controls
- Never trust user-controlled file paths
