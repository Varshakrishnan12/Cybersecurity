# VirtualBox Installation Guide

## Objective
Install Oracle VirtualBox to create virtual machines for cybersecurity labs.

## Prerequisites
- Windows 10/11
- At least 8 GB RAM
- 20 GB free disk space

## Step 1: Download VirtualBox
1. Visit the official VirtualBox website.(virtualbox.org)
2. Click Downloads.
3. Select Windows Hosts(Inside VirtualBox Platform Packages).

## Step 2: Run the Installer
1. Open the downloaded installer.
2. Click Next.
3. In the agreement, choose "I accept the terms of the license agreement. and click Next.
4. Choose the installation location.
5. Continue with default settings.
6. Click Install.

## Step 3: Complete Installation
1. Allow required network permissions.
2. Click Finish.

## Step 4: Verify Installation
1. Open VirtualBox.
2. Confirm the VirtualBox Manager opens successfully.

## Result
VirtualBox is installed and ready for creating virtual machines.
